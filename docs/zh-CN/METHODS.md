# 方法概览

[English](../METHODS.md) | [简体中文](METHODS.md)

本说明依据所提供的论文 *tSymPerturb converts longitudinal symptom networks into time-indexed intervention strategies* 整理。当前程序是方法规范的参考实现，不能据此认定因果治疗效应，也不代表已复现论文原始模拟结果。

## 1. 时间、方向与量纲

两波模型为 `X2 = a + B X1 + ε`。`B` 的行对应 T2 结局，列对应 T1 来源，因此 `B[j,i]` 表示 `i(T1) → j(T2)`，对角项为自身持续效应。所有症状应统一为数值越高、状态越差。

先在原始量表上定义锚点，再使用拟合时的 T1 均值与标准差转换至模型量纲。标准化后的 0 通常表示样本均值，不表示症状消失。结局改善应使用预设的、未扰动 T2 标准差进行标准化，不能随扰动重新选择分母。当前核心程序从模型隐含基线协方差 `B Σ1 Bᵀ + Ψ` 计算该分母；如果采用经验标准差，应另行明确约定。

## 2. 来源状态算子

时间虚拟敲降采用 `X1*[i] = c[i] + (1−d)(X1[i]−c[i])`；`d=1` 为时间虚拟敲除。非靶点来源变量保持不变。靶点方差乘以 `(1−d)^2`，靶点与非靶点间协方差乘以 `(1−d)`。

均值响应为 `R = B(mean1 − mean1*)`。单靶点响应为 `R_i(d) = d B[:,i](mean1[i]−c[i])`。扰动时保持已拟合的转移矩阵不变；每次虚拟干预后重新拟合网络，会改变所回答的问题。精确敲除产生常数来源变量，但无需再次标准化该变量。

若研究协方差，则使用 `Σ2* = B Σ1* Bᵀ + Ψ`。仅改变位置和同时改变位置与尺度，可以具有相同的均值响应，但产生不同的后续方差。

## 3. 转移算子

有向边阻断衰减一个 `B[j,i]`；来源节点阻断衰减第 `i` 列。必须说明是否包括自身持续路径。保持截距不变时，有符号预测变化为 `(B−B*) x_ref`，结果依赖参考状态。如果以均值中心化人群为参考，平均有符号变化为 0。

论文另外定义无符号路径容量：

`Q_H(B) = 1ᵀ [Σ(h=1…H) (γ |B|)^h] 1`

阻断后的相对容量损失属于拓扑诊断。由于正负路径均取绝对值，不能直接将其解释为症状获益。必须明确传播时域、衰减系数和阻断比例，这些均为分析设定。

## 4. tVPPS 的七个维度

| 维度 | 含义 |
|---|---|
| 总下游效力 | 包括靶点自身 T2 结局在内的加权标准化改善 |
| 跨症状溢出 | 排除靶点自身 T2 结局的加权改善 |
| 广度 | 达到预设改善阈值的非靶点结局比例 |
| 跨模块覆盖 | 平均改善达到阈值的其他模块比例 |
| 通信阻断价值 | 有限时域无符号路径容量的相对下降 |
| 组合价值 | 在预设配对集合中，正向增量组合价值的均值 |
| 溢出比例 | 正向非靶点获益占全部正向获益的比例 |

各维度在预先确定的候选集合内统一方向并进行 0–100 的 min–max 标准化；常数维度赋值为 50。tVPPS 为非负权重的加权平均，至少一个权重应大于 0。等权重仅为方法学默认设置，不代表已验证的临床偏好。应同时报告原始效用和标准化分数。

这七个时间维度与横断面 SymPerturb 不同。在线性参考模型中，剂量效率和低剂量响应性与效力代数冗余，不另设维度。稳健性与抽样不确定性须独立报告，不混入 tVPPS。

## 5. 三项可证伪约束

1. **剂量线性：** 在线性、无界的转移、剂量映射和均值效用下，`G_i(d) = d G_i(1)`。
2. **可加性：** 独立来源扰动满足 `R_{i,k} = R_i + R_k`；共同结局集上的线性效用，其加性交互对比为 0。
3. **时间可识别性：** 单一 T1→T2 观测转移不能识别反复治疗的先后顺序。

计算配对增量价值时，组合与两个单靶点均须使用同一结局集，并排除两个靶点。保留有符号增量 `I_ik = G_ik − max(G_i,G_k)`；虽然靶点层面参考效用平均的是 `max(0,I_ik)`，仍不应隐藏负值。增量组合价值不同于协同效应。

有界结局、非线性映射、交互项或状态依赖转移可以改变前两条恒等式，但必须明确额外机制并单独验证。

## 6. 多波传播与序列

单次扰动按实际观测顺序传播：`R_{t+h} = B_{t+h−1} … B_t δ_t`。在观测区间外重复使用同一矩阵，即 `B^h δ`，额外依赖平稳性假设。

反复干预采用 `Δ⁻_{t+1} = B_t(Δ⁻_t + u_t)`。应说明干预时点、传播时域、成本、折扣与可行性。两波数据上的靶点加入顺序是决策过程，不能被解释为生物学治疗顺序的证据。

## 7. 不确定性与报告

应用研究的 bootstrap 应重新执行参与者重抽样、标准化、锚点转换、网络估计、扰动、效用计算、标准化和排序。排序分布与进入前 K 名的概率独立报告。仅对最终得分表重抽样，不属于完整流程 bootstrap。[可选适配器](../../skills/tsymperturb/references/fitting-and-uncertainty.md)针对独立、完整、配对两波观测，以固定惩罚参数 Lasso 实现上述流程。它记录失败及来源–残差协方差；惩罚回归残差未必经验正交，模型隐含后续方差可以与经验方差不同。

至少报告测量波次与间隔、样本及缺失处理、症状方向与量纲、锚点、矩阵方向与估计器、结局标准差、候选与配对集合、模块、权重和阈值、阻断与时域设定、原始效用与 tVPPS、代数检查和局限。须区分当前脚本已计算的内容，以及仍需额外实现和验证的分析。
